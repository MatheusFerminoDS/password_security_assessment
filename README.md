# Password Security Assessment

**Auditoria de Mecanismos de Autenticação — Metasploitable 2 & DVWA**

## Sobre o projeto

Projeto prático de auditoria de segurança desenvolvido em ambiente controlado, utilizando Kali Linux e a ferramenta Medusa para estudar e simular ataques de força bruta contra mecanismos de autenticação.

O objetivo foi compreender vulnerabilidades relacionadas à autenticação, avaliar a exposição a tentativas automatizadas de acesso e identificar medidas de mitigação.

## Ambiente utilizado

- **Kali Linux:** sistema operacional utilizado nos testes.
- **Metasploitable 2:** máquina virtual vulnerável para práticas de auditoria.
- **DVWA:** aplicação web vulnerável utilizada nos testes de autenticação.
- **Medusa:** ferramenta para simulação de tentativas automatizadas de autenticação.
- **Nmap:** ferramenta para reconhecimento e identificação de serviços.
- **VirtualBox:** ambiente de virtualização.

## Atividades desenvolvidas

- Reconhecimento de serviços e portas com Nmap.
- Enumeração e análise de serviços FTP.
- Simulação de tentativas de autenticação com Medusa.
- Testes de força bruta em formulário web utilizando DVWA.
- Análise de mecanismos de autenticação e sessões.
- Estudo de técnicas de password spraying e enumeração de usuários SMB.
- Registro de evidências e análise dos resultados.
- Elaboração de recomendações de segurança.

- Compreender ataques de força bruta e password spraying.
- Desenvolver familiaridade com ferramentas de auditoria.
- Identificar falhas em mecanismos de autenticação.
- Interpretar resultados de testes de segurança.

## Considerações de segurança

Todos os testes foram desenvolvidos em ambiente de laboratório controlado, utilizando máquinas e aplicações intencionalmente vulneráveis.

Este projeto possui finalidade exclusivamente educacional. As técnicas demonstradas devem ser utilizadas somente em sistemas próprios ou com autorização expressa.
